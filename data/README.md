# Données

Le fichier `donnees_deplacement_PSpark 2026.xlsx` (enquête ménages-déplacements de la région de Dakar) a été fourni dans le cadre du module Big Data et **n'est pas publié dans ce dépôt**.

Pour exécuter le notebook, placez ce fichier sur votre machine et indiquez son chemin dans la variable `file` de la cellule 1.1.

Le notebook crée ensuite automatiquement le dossier `data/raw/` et y écrit une copie CSV de la feuille `deplacement`, lue par Spark.
